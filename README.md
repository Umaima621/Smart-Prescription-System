# 💊 Smart Prescription System

A Java-based desktop application designed to simplify prescription management by helping users organize medications, track prescriptions, and manage healthcare information efficiently. The project focuses on improving accessibility, reducing manual record-keeping, and providing a user-friendly interface for patients and healthcare providers.

## 🚀 Features

* 👤 Patient management
* 👨‍⚕️ Doctor management
* 💊 Prescription management
* ⏰ Medication reminders
* 💾 SQL Server database integration
* 🔍 Search and manage records
* 🖥️ JavaFX desktop interface
* 📊 Organized healthcare data management

## 🛠️ Tech Stack

* **Language:** Java
* **UI Framework:** JavaFX
* **Database:** Microsoft SQL Server
* **Database Management:** SQL Server Management Studio (SSMS)
* **IDE:** Eclipse
* **JDBC:** Microsoft SQL Server JDBC Driver

## 📂 Project Structure

```text
src/        → Java source code
lib/        → External libraries
Schema.sql  → Database schema
Report.docx → Project documentation
```

## ⚙️ Getting Started

1. Clone the repository.
2. Open the project in Eclipse.
3. Create the database using `Schema.sql`.
4. Configure the SQL Server connection in the project.
5. Add the required JDBC driver.
6. Run the application.
